## Syncthing: downloaded, not bundled

SyncThing V2 does **not** include Syncthing. If no Syncthing is installed, it downloads the official upstream release **Syncthing v2.1.5** from <https://github.com/syncthing/syncthing/releases/tag/v2.1.5> at run time. It checks the download against SHA-256 pins compiled into SyncThing V2, and keeps upstream's `LICENSE.txt`, `README.txt` and `AUTHORS.txt` next to the extracted program.

| Component | Version | Licence | Source code |
|---|---|---|---|
| Syncthing | v2.1.5 | MPL-2.0 (Mozilla Public License 2.0) | <https://github.com/syncthing/syncthing/tree/v2.1.5> |

- `github.com/goreleaser/nfpm/v2` v2.47.0 (MIT), for the Debian package

SyncThing V2 bundles no fonts. The dashboard uses the fonts already on your system. The app and tray icons are drawn by SyncThing V2's own code (`internal/icon`) and are covered by its MIT licence.
